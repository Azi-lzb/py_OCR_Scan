说明
宽表汇总
按 config 规则把源文件所有 sheet 摊平成宽表（pytools 3.9.8 同款）：行=源数据行（行头取合并格锚点，中缝表头也各占一行），列=列头路径，直接可 SUMIFS 引用。
国库数据校验归集
把多份「YYYY.MM 地区名.xls」指标表（代码/名称/行序号/余额）按文件名归集进时序表（每地区一 sheet、行=指标、列=月份），随后做总分校验（市级 vs Σ县区）与不应有数校验（惠阳/博罗/龙门），结果写进时序表的「校验结果」sheet。规则（取数列/容差/地区/白名单）在 config.xlsx 的「归集配置/地区规则/白名单」可配。
会计数据补录校验
录入系统前的数据处理：惠州市会计表 5 个费用指标（11367~11370、11631）全 0 时，从费用余额表按「补录映射」补录并联动父项，另存 *_已补录* 副本；随后与国库同口径归集校验进会计时序表。

界面模式
日间为纸张暖底，夜间为深色
主题色
8 个预设色，日/夜自动换浓淡变体
识别引擎
引擎档位
标准档：PP-OCRv4 轻量模型，速度快；高精度档：server 模型，数值与小字更准，速度约慢 2~3 倍。两档模型均已内置，离线可用。
自动旋转纠正
识别前自动纠正倒置/横放的照片。每张需多花数秒做方向探测；照片方向都已摆正时可关闭，明显提速。
离线说明
识别、表格结构、PDF 渲染、导出全部在本地完成，不访问网络。
月计表模板
自动匹配模板
识别时按结构区文本自动匹配模板 sheet。关闭后仅用每张图行内选择的 sheet（未选则不套模板）——预先把各图 sheet 手动选好可省去匹配开销。套用模板的页面按模板冻结行列与科目文本，只 OCR 数值格（最准、最快）。
模板管理
模板与工作表清单一律在顶部「模板库」页查看；新增模板：导出 Excel 存到模板目录后点「重新扫描」。
文件对话框
选择方式
自动＝桌面壳用系统原生、浏览器壳用 Tk。系统原生/Tk 对话框＝强制走指定通道。浏览器内置＝点「选择」直接弹浏览器选文件框，选中后读取并上传到本地服务，完全不依赖系统对话框——桌面壳对话框异常时可切到此项规避。
