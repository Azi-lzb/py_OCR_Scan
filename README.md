# OCR_Tools — 拍照表格 OCR + 数据校验归集（本地离线工具）

把**带打印框线的纸质表格**拍成照片，本地识别成可校对的表格，一键导出 Excel。
全程离线运行（OCR 模型内置），适合"手工录入系统前先录 Excel 做校验"的场景。

## 识别能力

| 项目 | 说明 |
|---|---|
| 表格类型 | 有完整框线的表格（线检测切格）；**无框线表格**（SLANet-Plus 模型结构识别，自动降级） |
| 纯文字页 | 无框线且不像表格的页自动转**整页文字识别**，按行输出（模式自动判断） |
| 输入 | 照片（jpg/png/bmp/tif/webp）、**PDF**（逐页自动展开）、**拖拽导入** |
| 页面方向 | 拍照透视自动拉正；扫描歪斜自动转正；**横放/倒放照片自动纠向** |
| 扫描件 | 自动清理边缘黑边；容忍低对比度、噪声、JPEG 压缩、低分辨率（自动放大） |
| 表格标题 | 自动识别表格上方大字标题，写入 Excel 首行（合并居中，可改） |
| 合并单元格 | 自动识别跨行/跨列合并，导出为 Excel/Word 合并单元格 |
| 校对辅助 | 低置信度单元格**标红**；数字列自动推断，异常值**标橙**；**点击表格单元格 ⇄ 预览图区域双向高亮联动**；预览/表格分栏高度可拖动；一键复制（可直接粘贴进 Excel） |
| 忽略区域 | 预览图上框选页眉/水印/印章等区域，识别时自动跳过 |
| 识别档位 | 标准档（mobile 模型，快）/ **高精度档**（server 模型，更准；模型已随程序内置，离线可用） |
| **月计表模板（xlsx）** | 模板即 Excel 文件：把校对好的一页"存为模板"后生成 .xlsx（命名区域「数字区域/结构区域」定义哪些格每月 OCR、哪些格冻结）。识别时用**表格外框+模板比例+文字锚点对齐**铺格，摆脱内部细线检测，尺寸差异与阴影都不受影响；结构区文本逐格校验。模板可用 Excel 直接查看编辑 |
| **勾稽公式** | 保存模板时自动按行生成勾稽差额公式（上期借-贷 + 本期发生借-贷 − 期末借-贷 = 0），列在「勾稽」表；导出时本地求值，不平的行在日志告警。可在 Excel 中对差额列加条件格式做可视化标记 |
| 内容 | 中文、英文、数字混合；纯数字自动转数值（可直接求和校验）；中文语境标点自动规范 |
| 速度 | 约 3~10 秒/张（CPU，标准档；高精度档约慢 2~3 倍） |

## 快速开始

### 1. 安装依赖（只需一次）

```
cd 10.ScanToExcel
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r shell-pywebview\requirements.txt
```

（使用 Flask 浏览器版则装 `shell-flask\requirements.txt`；两个都用就都装。）

### 2. 启动

双击其一：

- `shell-pywebview\启动OCR_Tools.bat` —— **推荐**，桌面窗口程序
- `shell-flask\启动Flask版.bat` —— 浏览器页面版（兼容性备用）

### 3. 打包成免安装 exe（可选）

```
.venv\Scripts\python.exe shell-pywebviewuild_exe.py   → dist\OCR_Tools\        （约 380 MB）
.venv\Scripts\python.exe shell-flaskuild_exe.py       → dist\OCR_Tools-Flask\  （约 378 MB）
```

文件夹版（PyInstaller onedir，`--clean --noconfirm` 全自动覆盖重建）：
exe + _internal + core/data 种子（config/模板「不存在才复制」，升级不覆盖用户数据）。
整个文件夹打 zip 即可分发到别的 Win10/11 机器。

## 数据处理与工具

- **数据处理**（三种模式，路径自动记忆）：
  - `宽表汇总`——把 OCR 导出结果按 pytools 3.9.8 同口径摊平成宽表，可去重追加到目标工作簿
  - `国库数据校验归集`——把多份「YYYY.MM 地区名.xls」指标表归集进时序表（每地区一 sheet、
    行=指标、列=月份），并做总分校验（市级 vs Σ县区）与不应有数校验，输出「校验结果」sheet
  - `会计数据补录校验`——惠州市费用指标全 0 时从费用余额表补录（联动父项、另存 *_已补录* 副本），
    再归集校验
  - 规则全部在 `core/data/config/config.xlsx`：归集配置 / 地区规则 / 白名单 / 补录映射
- **工具**：批量转换 xls/xlsx/xlsm/csv 与 doc/docx（引擎自动择优 MS Office / WPS，
  输出到源目录的「目标格式」子文件夹）

## 使用流程

1. **导入**：点"选择照片/PDF…"或**直接把文件拖进窗口**（PDF 自动逐页展开）
2. **开始识别**：后台逐张识别；预览区可切换"原图 / 识别叠加"确认识别情况
   （表格页显示切分框线，无框线表格显示结构模型单元格框，文字页显示绿框）
3. **框选忽略区域**（可选）：在预览图上拖框圈出页眉/水印/印章，重新识别后跳过
4. **识别文字（当前页）**：把当前页强制按整页文字识别（表格页也能提纯文字）
5. **校对**：表格标题和结果表**均可点击直接修改**；红底=识别置信度低（重点核对），
   橙底=数字列出现非数字内容（疑似错位/错字）；顶部**复制**按钮可整表复制后
   直接粘贴进 Excel
6. **导出**（均生成全新文件，选择已有文件会整体覆盖、绝不追加）：
   - **导出 Excel**：所有照片进**一张工作簿**，每张一个 Sheet
   - **导出 Word**：所有照片进一个文档；表格页渲染为 Word 表格（含合并单元格），
     文字页为逐行段落
   - **更多导出**：CSV（当前页）/ TXT / Markdown / JSON（全部页）
7. 导出后可一键打开文件

## 月计表（固定格式报表）推荐用法

每月都要做的固定表格（会计月计表等），最优流程：

1. **采集**：优先**扫描成 PDF**（走扫描仪，页正、无阴影）＞手机扫描 App（自动去阴影拉正，导出 PDF）＞直拍。直拍也能用模板模式，但版式偏差会影响套用精度。
2. **首月**：正常识别一页 → 在界面里校对（改错字/补漏）→ 点**存为模板**（模板冻结这一页的行列结构、科目代码与名称、表头文字）。
3. **以后每月**：导入当月照片/PDF → 识别时**自动套用模板**（设置页可开关）→ 只有数值格参与 OCR，科目代码列自动校验、异常行在列表里显示 ⚠ 提示。
4. 模板模式的优势：列线检测在阴影下不稳的问题被绕开（列边界来自模板而不是检测）；科目名永不出现 OCR 错误；识别更快。

模板文件存放在 `core/data/templates/`，在设置页可查看与删除。

## 拍照建议（识别更准）

- 表格线完整清晰、无严重反光遮挡
- 尽量正对拍摄（轻微倾斜可自动校正）
- 分辨率别太低：文字高建议 ≥ 20 像素（低清图会自动放大补救，但源头清晰更好）
- 固定格式报表优先用扫描 PDF + 月计表模板模式（见上）

## 常见问题

- **某页显示"文字 N 行"**：该页没有检测到表格框线，自动走了整页文字识别；如本该是表格，请重拍更清晰的照片（框线完整）
- **导出的 Excel 数字是文本**：工具会自动转换纯数字（含千分位/百分数），混杂其他字符的保持文本
